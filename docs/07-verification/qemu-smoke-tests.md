# QEMU Smoke Tests

## Objective

Verify boot, readiness, networking, systemd health, application health, version identity, Mender client readiness, evidence collection, timeout, and cleanup.

## Evidence Requirements

- Test identifier and version
- Requirement identifiers
- Environment and input revisions
- Start and end time
- Result and failure reason
- Artifact checksums
- Evidence location
- Reviewer

## Pass Rule

A pass requires all mandatory expectations. A partial result is recorded as failed or blocked, never silently accepted.
