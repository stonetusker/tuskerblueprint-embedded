# Glossary

| Term | Meaning |
|---|---|
| BitBake | Task executor and metadata engine used by Yocto |
| Poky | Yocto Project reference distribution and build system integration |
| sstate | Shared-state cache containing reusable task outputs |
| DL_DIR | Yocto downloads directory |
| QEMU | Machine emulator used for headless ARM64 validation |
| OTA | Over-the-air software update |
| Mender Artifact | Signed update package delivered by Mender |
| Release Candidate | Immutable tested artifact awaiting promotion |
| MCP | Model Context Protocol used to expose constrained tools and data |
| Human Approval | Explicit authorization recorded outside the AI model |
| SensorNode | Fictional embedded device implemented by this project |
