# Roles and Responsibilities

| Role | Accountability |
|---|---|
| Project Owner | Scope, business outcome, public claims, final approval |
| Principal Embedded Engineer | Yocto, image design, QEMU target, OTA integration |
| Platform Engineer | Runner, CI, MinIO, Jenkins, infrastructure automation |
| Security Reviewer | Signing, secrets, access, threat model, AI controls |
| Test Engineer | Verification strategy, QEMU tests, rollback evidence |
| Content Owner | Episode accuracy, evidence use, public repository quality |
| Human Approver | Consequential rebuild, promotion, deployment, and rollback authorization |

One person may hold multiple roles, but approval evidence must still identify the acting role.
