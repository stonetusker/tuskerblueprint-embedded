# Project Principles

1. Specification before implementation.
2. One build implementation, multiple orchestrators.
3. Deterministic tests before AI judgment.
4. Human approval for consequential execution.
5. Immutable promotion of the tested artifact.
6. Least privilege for users, services, and AI.
7. Reproducible and pinned inputs.
8. Evidence-backed public claims.
9. Standalone operation with a defined shared-platform migration path.
10. Honest distinction between QEMU validation and physical-board validation.
