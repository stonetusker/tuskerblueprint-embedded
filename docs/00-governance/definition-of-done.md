# Definition of Done

A work item is done when:

- The implementation is reviewed and merged.
- Automated tests pass.
- Required manual verification is recorded.
- Requirements and tests are traceable.
- Security checks pass.
- Runbooks and architecture documents are current.
- Evidence is retained.
- Rollback behavior is known.
- The specification status is updated to Verified.

A release additionally requires a signed artifact, SBOM, manifest, approval record, passing QEMU evidence, and successful canary validation.
