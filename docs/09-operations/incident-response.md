# Incident Response

## Objective

Classify incidents by source compromise, credential exposure, runner compromise, release integrity, service outage, or AI control failure. Contain, preserve evidence, revoke access, restore trusted state, and document lessons.

## Preconditions

- Authorized operator
- Current infrastructure inventory
- Known service version
- Backup or rollback path
- Evidence destination

## Completion Record

Record operator, time, target, actions, result, exceptions, and follow-up.
